## 🌟 核心特色

1. **手機鎖屏背景連播（防休眠）**：
   * **靜音循環錨定技術（Silent Audio Anchor）**：解決行動瀏覽器於間隔停頓時掛起 JavaScript 計時器的問題，鎖定螢幕依然順暢連播。
   * **持久化單一 Audio 管道**：初次點擊播放後重複使用同一實例，跨曲目無縫換源。
   * **原生 MediaSession 鎖屏控制器**：手機鎖定螢幕、通知列與藍牙耳機上即時顯示曲名、族語與中文，並支援上下首切換。
   * **Screen WakeLock**：螢幕點亮時保持喚醒，關閉螢幕時無縫轉移至背景音訊管線。

2. **1.5～3 歲幼兒專屬「磨耳朵模式」**：
   * 🎧 **沉浸磨耳朵**：族語播放 2 次 ＋ 中文翻譯 1 次 ➔ 自動切換下一句。
   * 🌿 **純母語環境**：純族語播放 2 次（完全無中文干擾，適合遊戲時當背景母語環境或睡前聆聽）。
   * 🎶 **歌謠大合唱**：兒歌全曲連續自動播放。
   * 🎯 **單次精聽**：族語 1 次 ＋ 中文 1 次。
   * 語速微調（`0.8x` 慢速、`0.9x` 溫和、`1.0x` 正常）、句間停頓反應時間（`1.0s`～`3.0s`）、睡前定時關閉（`15分`～`60分`）。
